# SKILL 工程

SKILL 工程项目，包含场景引擎和相关组件的实现。

## 项目结构

```
SKILLs/
├── scenario_engine/          # 场景引擎模块
├── README.md                 # 项目说明
├── .gitignore               # Git 忽略配置
└── ...
```

## 开始使用

### 环境要求

- Python 3.8+
- Git

### 安装依赖

```bash
pip install -r requirements.txt
```

## 分支管理

- `main/master` - 主分支，用于生产发布
- `dev` - 开发分支，用于功能开发和测试
